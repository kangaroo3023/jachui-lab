## 한눈에 보는 자취방 인터넷 선택

이 글의 핵심부터 먼저 정리합니다.

| 항목 | 내용 |
|------|------|
| 3대 통신사 (KT·SKB·LGU+) | 월 2.5~3.3만원 (500M 기준) |
| 알뜰 인터넷 | 월 1.5~2만원 (같은 회선) |
| 설치 소요 시간 | 신청 후 3~7일 |
| 약정 | 보통 3년, 위약금 있음 |
| 추천 속도 | 혼자 쓰면 100~500Mbps면 충분 |
| 공유기 | 통신사 제공 or 별도 구매 |

자취방에 이사하면 가장 먼저 해야 하는 게 인터넷 설치예요. 근데 통신사마다 요금이 다르고, 약정이니 위약금이니 복잡해서 뭘 골라야 할지 모르겠잖아요. 결론부터 말하면, 자취생은 알뜰 인터넷이 가장 가성비 좋아요.

## 인터넷 설치 전에 확인할 것

신청하기 전에 반드시 체크해야 하는 게 있어요.

**1. 기존 인터넷이 있는지 확인**

원룸이나 오피스텔은 건물주가 이미 인터넷을 깔아놓은 경우가 많아요. 이걸 "구내 인터넷"이라고 해요. 관리비에 포함되어 있으면 별도 설치 없이 바로 쓸 수 있어요.

| 유형 | 특징 | 추가 비용 |
|------|------|---------|
| 구내 인터넷 포함 | 관리비에 포함, 바로 사용 가능 | 없음 |
| 구내 인터넷 선택 | 건물에 회선은 있지만 개별 신청 필요 | 월 1~1.5만원 |
| 개별 설치 | 직접 통신사에 신청 | 월 2~3.3만원 |

계약서를 보거나 집주인·관리실에 물어보면 알 수 있어요. 관리비에 "인터넷" 항목이 있으면 구내 인터넷이 포함된 거예요.

**2. 구내 인터넷 속도가 괜찮은지**

구내 인터넷은 건물 전체가 하나의 회선을 나눠 쓰는 구조라서 속도가 느린 경우가 있어요. 입주 후에 속도 테스트를 해보세요. 네이버에서 "인터넷 속도 측정"을 검색하면 바로 테스트할 수 있어요.

다운로드 50Mbps 이상이면 유튜브·넷플릭스 문제없어요. 20Mbps 이하면 느린 편이니까 개별 설치를 고려해야 해요.

**3. 벽에 인터넷 포트가 있는지**

방 벽면에 인터넷 포트(랜선 꽂는 구멍)가 있는지 확인하세요. 있으면 설치가 간단해요. 없으면 통신사 기사님이 외부에서 선을 끌어와야 하는데, 집주인 동의가 필요할 수 있어요.

## 통신사별 인터넷 요금 비교 (2026년 기준)

3대 통신사의 일반 가정용 인터넷 요금이에요. 약정 3년 기준이에요.

| 속도 | KT | SK브로드밴드 | LG유플러스 |
|------|-----|-----------|----------|
| 100M | 월 ~2.2만원 | 월 ~2만원 | 월 ~2만원 |
| 500M | 월 ~2.8만원 | 월 ~2.5만원 | 월 ~2.5만원 |
| 1G | 월 ~3.3만원 | 월 ~3만원 | 월 ~3만원 |

실제 요금은 프로모션, 결합 할인, 가입 경로에 따라 달라져요. 위 금액은 대략적인 참고용이에요.

**통신사별 특징**

| 통신사 | 장점 | 단점 |
|--------|------|------|
| KT | 가장 넓은 커버리지, 안정적 | 가격이 조금 더 비쌈 |
| SK브로드밴드 | 가격 경쟁력, TV 결합 할인 | 일부 지역 커버리지 약함 |
| LG유플러스 | 가격 경쟁력, 공유기 성능 괜찮음 | 일부 구형 건물 설치 어려움 |

자취생이 혼자 쓰는 거라면 솔직히 세 곳 다 큰 차이 없어요. 가격이 가장 중요하다면 그때그때 프로모션이 좋은 곳을 고르세요.

## 알뜰 인터넷 — 자취생 최고의 선택

알뜰폰 아시죠? 인터넷도 똑같은 구조가 있어요. KT·SK·LG의 실제 회선을 빌려서 더 싸게 파는 거예요. 속도와 품질은 동일한데 가격만 저렴해요.

| 알뜰 인터넷 | 회선 | 500M 요금 | 특징 |
|-----------|------|---------|------|
| 스마트플러스 | KT | 월 ~1.7만원 | 약정 없는 요금제 있음 |
| 홈플러스 인터넷 | SK | 월 ~1.8만원 | 홈플러스 결합 할인 |
| 인터넷나야나 | KT/SK | 월 ~1.6만원 | 최저가 경쟁 |
| 딜라이브 | 자체 | 월 ~1.5만원 | 서울·수도권 한정 |

요금은 수시로 바뀌니까 가입 전에 반드시 최신 요금을 확인하세요.

**알뜰 인터넷 장단점**

| 장점 | 단점 |
|------|------|
| 같은 회선인데 월 1만원 이상 저렴 | 고객센터 응대가 느릴 수 있음 |
| 약정 없는 요금제 선택 가능 | 설치 기사 방문이 조금 늦을 수 있음 |
| 위약금 부담 적음 | TV·전화 결합 할인 폭이 작음 |

자취생은 TV 결합할 일도 별로 없고, 고객센터 전화할 일도 거의 없잖아요. 그러면 알뜰 인터넷이 압도적으로 유리해요. 월 1만원 아끼면 1년에 12만원이에요.

![노트북으로 인터넷 속도 테스트](https://images.unsplash.com/photo-1544197150-b99a580bb7a8?w=800&auto=format&fit=crop&q=80)

## 속도는 얼마나 필요할까

자취생이 혼자 쓴다면 1기가까지 갈 필요 없어요.

| 용도 | 필요 속도 | 추천 요금제 |
|------|---------|----------|
| 유튜브·넷플릭스 HD | 25Mbps | 100M이면 충분 |
| 넷플릭스 4K | 50Mbps | 100~500M |
| 온라인 게임 (롤, 발로란트) | 속도보다 핑이 중요 | 100M + 유선 연결 |
| 대용량 다운로드 자주 | 빠를수록 좋음 | 500M~1G |
| 화상회의 (재택근무) | 50Mbps 이상 | 100~500M |

대부분의 자취생은 100Mbps면 넉넉하고, 여유 있게 잡아도 500Mbps면 뭘 해도 부족함이 없어요. 1기가는 여러 명이 동시에 쓰거나 대용량 작업을 할 때나 필요해요.

## 인터넷 설치 과정

신청부터 설치까지 이렇게 진행돼요.

| 단계 | 할 일 | 소요 시간 |
|------|------|----------|
| 1 | 통신사 또는 알뜰 인터넷 온라인 신청 | 10분 |
| 2 | 상담 전화 (설치 일정 확인) | 당일~익일 |
| 3 | 설치 기사 방문 | 신청 후 3~7일 |
| 4 | 회선 연결 + 공유기 설치 | 30분~1시간 |
| 5 | 속도 테스트 후 사용 시작 | 바로 |

**설치 당일 팁**

- 기사님이 오기 전에 공유기 놓을 위치를 정해두세요. 방 중앙에 가까울수록 와이파이가 잘 돼요
- 랜선이 필요하면 미리 말해두세요. 기본 제공은 짧은 경우가 많아요
- 설치 후 바로 속도 테스트를 해보세요. 계약한 속도의 70~80% 이상 나오면 정상이에요
- 속도가 너무 느리면 그 자리에서 기사님에게 말하세요. 나중에 하면 번거로워져요

## 공유기(와이파이) — 통신사 걸 쓸까, 따로 살까

통신사에서 설치할 때 공유기를 같이 줘요. 임대 형태라 매달 비용이 포함되어 있거나, 무상 제공인 경우도 있어요.

| 구분 | 통신사 제공 공유기 | 별도 구매 공유기 |
|------|--------------|-------------|
| 비용 | 월 임대료 포함 or 무상 | 3~8만원 1회 구매 |
| 성능 | 보통 (원룸이면 충분) | 선택에 따라 고성능 가능 |
| 설정 | 기사님이 해줌 | 직접 설정 (어렵지 않음) |
| 추천 대상 | 대부분의 자취생 | 게이머, 기기 많은 사람 |

원룸이면 통신사 공유기로 충분해요. 방이 작으니까 와이파이 커버리지 문제가 거의 없거든요. 괜히 비싼 공유기 살 필요 없어요.

다만 이런 경우에는 별도 공유기를 추천해요.

- 와이파이가 자주 끊기거나 느릴 때
- 연결 기기가 10개 이상일 때 (노트북, 태블릿, 스마트폰, 스마트워치, IoT 등)
- 온라인 게임을 자주 해서 핑이 중요할 때

## 약정과 위약금 — 이사 갈 때 어떡하나

자취생에게 가장 골치 아픈 게 약정이에요. 보통 3년 약정을 맺는데, 자취방을 그렇게 오래 사는 경우가 드물잖아요.

**이사할 때 선택지**

| 방법 | 조건 | 비용 |
|------|------|------|
| 이전 설치 | 새 주소에서 같은 통신사 사용 | 이전 설치비 1~3만원 |
| 약정 승계 | 다음 세입자에게 넘기기 | 무료 |
| 중도 해지 | 위약금 납부 후 해지 | 남은 기간에 따라 다름 |
| 약정 없는 요금제 | 애초에 약정 안 맺기 | 월 요금이 조금 더 비쌈 |

**가장 좋은 방법은 이전 설치예요.** 같은 통신사를 계속 쓰면서 주소만 바꾸는 거라 위약금이 없어요. 이전 설치비만 내면 돼요.

이사를 자주 할 것 같다면 처음부터 약정 없는 요금제를 고르세요. 알뜰 인터넷 중에 약정 없이 월 2만원 이하인 곳이 있어요. 월 3~5천원 더 내더라도 위약금 걱정이 없는 게 낫잖아요.

**위약금 계산법** — 대부분 통신사는 남은 약정 개월 × 할인받은 금액으로 계산해요. 예를 들어 월 1만원 할인받고 있었는데 12개월 남았으면 약 12만원이에요. 정확한 금액은 고객센터에서 확인할 수 있어요.

## 인터넷 느릴 때 체크리스트

설치했는데 느리다고 바로 통신사 탓하기 전에 이것부터 확인하세요.

| 확인 항목 | 해결 방법 |
|---------|---------|
| 공유기 위치가 구석에 있음 | 방 중앙으로 이동, 바닥보다 높은 곳에 |
| 공유기에 기기가 너무 많이 연결 | 안 쓰는 기기 연결 해제 |
| 5GHz 대신 2.4GHz에 연결 | 5GHz 와이파이에 연결 (속도 더 빠름) |
| 공유기를 오래 안 껐음 | 전원 뽑고 30초 후 다시 켜기 |
| 벽 너머로 와이파이 사용 | 공유기 위치 변경 or 유선 연결 |

5GHz와 2.4GHz 차이가 꽤 커요. 5GHz는 속도가 빠르지만 벽을 잘 못 뚫고, 2.4GHz는 느리지만 범위가 넓어요. 원룸이면 벽이 없으니까 5GHz에 연결하는 게 항상 유리해요. 와이파이 이름 뒤에 "5G"가 붙은 게 5GHz예요.

## 신청 전 체크리스트

| 순서 | 확인 항목 | 체크 |
|------|---------|------|
| 1 | 구내 인터넷 여부 확인 (관리비 내역 or 관리실 문의) | ☐ |
| 2 | 구내 인터넷 속도 테스트 (있는 경우) | ☐ |
| 3 | 벽면 인터넷 포트 확인 | ☐ |
| 4 | 예상 거주 기간 확인 (약정 기간 결정) | ☐ |
| 5 | 통신사 vs 알뜰 인터넷 요금 비교 | ☐ |
| 6 | 결합 할인 가능 여부 (휴대폰 같은 통신사) | ☐ |
| 7 | 온라인 신청 (전화보다 프로모션 더 좋은 경우 많음) | ☐ |

## 한 달 만원 아끼는 건 큰 차이입니다

인터넷은 한 번 설치하면 매달 나가는 고정비예요. 월 1만원 차이가 1년이면 12만원, 3년이면 36만원이에요. 통신사 대리점에서 권유하는 대로 가입하지 말고, 알뜰 인터넷부터 비교해보세요.

자취방에서 혼자 쓰는 거라면 100~500M 알뜰 인터넷이면 유튜브, 넷플릭스, 게임 다 돼요. 이사 자주 할 것 같으면 약정 없는 요금제를 선택하고요. 10분 투자해서 온라인으로 신청하면 3~7일 안에 설치 완료됩니다.
