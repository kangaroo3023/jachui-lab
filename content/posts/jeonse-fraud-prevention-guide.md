## 전세사기, 숫자로 보면 더 무섭습니다

2023년 기준 전세사기 피해 신고 건수는 약 2만 건. 피해 금액은 수조원 규모로 추산됩니다. "설마 나한테?"라고 생각하기 쉽지만, 피해자 대부분이 20~30대 1인가구였어요. 특히 빌라 밀집 지역에서 집중적으로 발생했죠.

전세사기를 한마디로 정리하면 이렇습니다.

> **"보증금 받아 놓고 돌려줄 능력이 없는 상태로 계약하는 것"**

### 깡통전세 구조 이해

| 항목 | 금액 |
|---|---|
| 집 시세 | 2억 원 |
| 은행 근저당(대출) | 1억 5천만 원 |
| 전세보증금 | 1억 원 |
| **대출 + 보증금 합계** | **2억 5천만 원** |

집값은 2억인데 걸려 있는 돈이 2억 5천. 5천만 원이 마이너스입니다. 경매에 넘어가면 은행이 먼저 가져가고, 세입자에게 돌아올 돈은 없어요.

### 전세사기 주요 유형

| 유형 | 수법 | 등기부등본으로 확인 가능 여부 |
|---|---|---|
| 깡통전세 | 대출 + 보증금 > 집값 | 을구에서 확인 가능 |
| 이중계약 | 한 집에 여러 세입자와 계약 | 갑구 소유자 확인으로 일부 대응 |
| 대리인 사기 | 집주인이 아닌 사람이 계약 | 갑구 소유자 대조로 차단 |
| 신탁 물건 사기 | 신탁회사 동의 없이 전세 계약 | 갑구에 신탁 등기 표시 확인 |

등기부등본 하나만 제대로 읽을 줄 알면 네 가지 유형을 전부 걸러낼 수 있습니다.

## 등기부등본이란 — 집의 신분증

사람에게 주민등록등본이 있듯, 집에는 등기부등본이 있어요. 이 문서에는 집 주소, 소유자, 대출 현황, 법적 문제 여부가 전부 담겨 있습니다.

**딱 세 파트만 보면 됩니다.** 표제부, 갑구, 을구.

### 등기부등본 구성 한눈에 보기

| 구분 | 내용 | 핵심 확인 포인트 |
|---|---|---|
| **표제부** | 집의 기본 정보 (주소, 면적, 구조) | 계약서 주소와 일치 여부 |
| **갑구** | 소유권 관련 사항 (소유자, 가압류 등) | 임대인과 소유자 동일인 여부, 가압류·가처분 유무 |
| **을구** | 소유권 외 권리 (근저당, 전세권 등) | 근저당 채권최고액 + 보증금 < 시세 70% 여부 |

## 등기부등본 떼는 법 — 700원이면 끝

집에서 5분이면 됩니다.

1. **[인터넷등기소](https://www.iros.go.kr)** 접속
2. 회원가입 (공동인증서 필요)
3. **"열람하기"** 클릭 → 부동산 선택
4. 주소 입력
5. **열람 수수료 700원** 결제
6. PDF로 바로 확인

> **팁**: "발급"이 아니라 **"열람"**을 선택하면 700원이에요. 내용은 동일하고 프린트 필요 없이 화면으로 확인하면 충분합니다.

정부24(gov.kr)에서도 가능하지만, 부동산 전문인 인터넷등기소가 더 편해요. 스마트폰으로는 대법원 "등기소 모바일" 앱을 활용하면 됩니다.

## 등기부등본 읽는 법 — 파트별 상세 가이드

### 1. 표제부 — 집의 기본 스펙

| 확인 항목 | 확인 포인트 |
|---|---|
| 소재지번 | 계약하려는 집 주소와 정확히 일치하는지 |
| 건물 내역 | 면적(㎡)이 부동산에서 말한 것과 같은지 |
| 건물 구조 | 철근콘크리트, 벽돌 등 (참고용) |

주소가 다르면 빨간불이에요. 부동산에서 보여주는 주소와 등기부등본 주소가 다른 경우가 간혹 있습니다.

### 2. 갑구 — 집의 진짜 주인

소유권에 관한 사항이 여기 있어요.

- **소유자 이름**: 계약서의 임대인과 100% 일치해야 합니다
- **소유자 주민번호 앞자리**: 계약 시 신분증과 대조
- **소유권 이전 날짜**: 최근 1~2년 내 여러 번 바뀐 집은 주의
- **가압류/가처분 여부**: 이게 있으면 계약하면 안 돼요

가압류란 누군가 집주인에게 돈을 받지 못해 법원을 통해 처분을 막아둔 상태를 말합니다. 법적 분쟁 중인 집에 들어가면 보증금을 잃을 위험이 커요.

### 3. 을구 — 집에 걸린 빚 (가장 중요)

근저당권, 즉 집을 담보로 받은 대출 정보가 여기 나옵니다. 경매 시 은행이 먼저 돈을 가져가고, 세입자는 후순위예요.

| 확인 항목 | 확인 포인트 |
|---|---|
| 근저당권자 | 어느 은행(또는 개인)에서 빌렸는지 |
| 채권최고액 | 실제 대출의 120~130% 정도로 잡혀 있음 |
| 설정 날짜 | 언제 대출을 받았는지 |

**핵심 공식:**

> **근저당 채권최고액 + 내 전세보증금 < 집 시세의 70%**

이 조건을 충족해야 비교적 안전합니다. 예시로 살펴볼게요.

- 집 시세 3억 원 → 70% = 2억 1천만 원
- 근저당 1억 + 보증금 1억 = 2억 → **안전** (2억 1천 미만)
- 근저당 1억 5천 + 보증금 1억 = 2억 5천 → **위험** (2억 1천 초과)

을구에 아무것도 없으면 대출이 하나도 없다는 뜻이에요. 가장 이상적인 상황이죠.

## 위험 신호 체크리스트

| 번호 | 위험 신호 | 확인 방법 |
|---|---|---|
| 1 | 근저당 + 보증금 > 집값 70% | 을구 채권최고액 + 보증금 계산 |
| 2 | 소유자가 최근 1~2년간 여러 번 변경 | 갑구 소유권 이전 이력 확인 |
| 3 | 신탁 등기가 되어 있음 | 갑구에 "신탁" 표시 여부 확인 |
| 4 | 가압류 또는 가처분 등기 존재 | 갑구에 기재 여부 확인 |
| 5 | 집주인이 등기부등본 열람을 꺼림 | 직접 열람으로 대응 (700원) |

이 중 하나라도 해당되면 그 집은 넘기세요. 보증금보다 중요한 건 안전이에요.

집값 시세는 국토교통부 실거래가 공개시스템(rt.molit.go.kr), 네이버 부동산, KB부동산에서 확인하세요. 중개사가 말하는 시세만 믿으면 안 됩니다. 반드시 직접 교차 확인이 필요해요.

## 전세보증보험 가입 — 최후의 안전망

등기부등본이 사전 예방이라면, 전세보증금반환보증은 최후의 방어선입니다. 집주인이 보증금을 안 돌려주면, 보증기관이 대신 지급하는 구조예요.

### 보증기관 비교

| 기관 | 보증료 수준 | 특징 | 가입 난이도 |
|---|---|---|---|
| **HUG (주택도시보증공사)** | 연 0.115~0.154% | 가장 많이 이용, 저렴 | 보통 |
| **SGI서울보증** | 연 0.2~0.3% | HUG 불가 시 대안 | 비교적 쉬움 |
| **한국주택금융공사 (HF)** | 전세대출 연계 | 전세자금대출과 함께 가입 | 대출 필수 |

보증금 1억 기준 HUG 보증료는 연 11만~15만 원. 월 1만 원 수준으로 1억을 지킬 수 있습니다.

### HUG 가입 조건

- 전세계약서 + 확정일자 필요
- 전입신고 완료 상태
- 전세보증금 수도권 7억 원 이하 (비수도권 5억 원 이하)
- 전세가율 100% 이하

### 가입 절차

1. 전세 계약 체결 (계약서 확보)
2. 전입신고 + 확정일자 받기
3. HUG 홈페이지 또는 은행 방문 → 보증 신청
4. 심사 후 보증서 발급 (보통 1~2주)

> 입주 후 최대한 빨리 가입하세요. 전세 기간의 절반이 지나면 가입이 안 되는 경우도 있습니다.

## 계약 전·당일·입주일 체크리스트

### 계약 전

- [ ] 등기부등본 열람 (인터넷등기소, 700원)
- [ ] 표제부: 주소·면적 일치 확인
- [ ] 갑구: 소유자 = 계약서 임대인 일치 확인
- [ ] 을구: 근저당 + 보증금 < 시세 70% 확인
- [ ] 집값 시세 2곳 이상 교차 확인 (국토부, KB 등)
- [ ] 건축물대장 열람 — 불법 건축물, 용도 확인 (정부24 무료)
- [ ] 임대인 신분증 대조

### 계약 당일

- [ ] 특약사항 명시: "계약 기간 중 근저당 추가 설정 불가" 등
- [ ] 계약금은 반드시 임대인 본인 계좌로 입금
- [ ] 계약서 사본 확보 (원본 + 사진)

### 입주 당일

- [ ] 잔금 전 등기부등본 재확인 (근저당 추가 여부)
- [ ] 전입신고 (주민센터 또는 정부24 온라인)
- [ ] 확정일자 받기 (주민센터, 600원)
- [ ] 전세보증금반환보증 가입 신청

전입신고와 확정일자, 이 두 가지가 핵심입니다. 경매 시 우선변제권(먼저 돈 받을 권리)이 여기서 생겨요.

## 자주 묻는 질문

### "부동산 중개사가 안전하다고 하면 믿어도 되나요?"

직접 확인이 원칙입니다. 대부분의 중개사는 성실하게 일하지만, 등기부등본의 모든 내용을 세세하게 설명해주지 않는 경우가 많아요. 드물게 집주인과 공모하는 사례도 있었습니다. 700원이면 직접 확인할 수 있는 건데, 남의 말만 믿을 이유가 없죠.

### "오피스텔도 전세사기가 있나요?"

오히려 더 많습니다. 시세 파악이 아파트보다 어렵고, 호수마다 가격 차이가 커서 깡통전세를 만들기 쉬워요. 업무용으로 등기된 오피스텔은 주택임대차보호법 보호를 제대로 못 받을 수 있으니, 건축물대장에서 **"주거용" 등록 여부**를 꼭 확인하세요.

### "빌라가 특히 위험한가요?"

통계적으로 전세사기 피해는 빌라에서 가장 많이 발생합니다. 비교 거래 사례가 적어 가격 부풀리기가 쉽고, 감정가와 실거래가의 괴리도 큰 편이에요. 빌라 전세라면 등기부등본 확인의 중요성이 아파트보다 훨씬 높습니다.

### "이미 전세사기를 당한 것 같으면?"

1. 증거 확보 — 계약서, 입금 내역, 문자·카톡 대화 전부 보관
2. 임차권등기명령 신청 — 이사 후에도 대항력 유지 가능
3. 전세사기 피해지원센터 연락 — 국토교통부 운영 (1533-8119)
4. 법률구조공단 무료 상담 — 대한법률구조공단 (132)
5. 사기 혐의가 명확하면 경찰 고소장 접수

전세사기 피해자 지원 특별법에 따라 보증금 반환이나 긴급 주거 지원을 받을 수 있는 경우도 있어요.

### "전세 말고 월세가 더 안전한가요?"

보증금 규모가 작으니 위험도 줄어드는 건 맞습니다. 하지만 월세 보증금 사기도 존재해요. 등기부등본 확인과 전입신고·확정일자는 전세든 월세든 필수입니다.

## 오늘 당장 할 3가지

1. **인터넷등기소 회원가입** — 당장 집을 구하지 않더라도 미리 해두면 급할 때 바로 열람 가능 → [인터넷등기소 바로가기](https://www.iros.go.kr)
2. **지금 사는 집 등기부등본 한번 떼보기** — 연습 겸 현재 집 상태 파악. 700원이면 됩니다.
3. **이 글 저장 또는 공유** — 전세사기는 "나는 아니겠지"라고 생각하는 사람에게 일어납니다

등기부등본 보는 법을 알면 보증금을 지킬 확률이 확 올라가요. 700원짜리 문서 하나가 수천만 원을 지켜줍니다. 5분이면 충분하고요.
