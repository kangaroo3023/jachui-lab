## 핵심 요약

| 항목 | 내용 |
|---|---|
| 곰팡이 번식 조건 | 습도 60% 이상에서 48시간이면 시작 |
| 제거보다 중요한 것 | 예방 (비용 3배 절감) |
| 예방의 3요소 | 환기 + 제습 + 단열 |
| 부위별 약품이 다른 이유 | 벽지에 락스 → 변색, 실리콘에 알콜 → 효과 없음 |
| 월 예방 비용 | 약 3만 원 (제습기 전기료 포함) |

곰팡이는 습도 60% 이상, 48시간이면 번식을 시작합니다. 제거 후 환경을 바꾸지 않으면 2~3개월 내 재발하니, 제거와 예방을 반드시 함께 해야 해요.

## 원인부터 파악해야 재발을 막아요

곰팡이가 어디에 생겼느냐에 따라 원인이 다릅니다. 원인을 모르고 닦기만 하면 몇 달 뒤 다시 올라와요.

### 부위별 원인과 위험도

| 부위 | 원인 | 위험도 |
|---|---|---|
| 벽 모서리·천장 | 단열 부족 + 결로 | 높음 |
| 창틀 고무 패킹 | 결로수 방치 | 중간 |
| 욕실 실리콘 | 물때 + 환기 부족 | 중간 |
| 옷장 내부 | 습기가 갇힘 | 높음 |
| 주방 싱크대 밑 | 배관 누수 가능성 | **최고** |

싱크대 밑 곰팡이는 누수 신호일 수 있습니다. 가볍게 넘기지 마세요.

![곰팡이 제거 스프레이를 준비하는 모습](https://images.unsplash.com/photo-1563453392212-326f5e854473?w=800&auto=format&fit=crop&q=80)

### 집주인에게 바로 연락해야 하는 경우

아래 세 가지는 세입자 잘못이 아닙니다. 집주인이 수선할 의무가 있고, 안 해주면 **임차인 수선청구권**(민법 제623조)을 행사할 수 있어요.

1. 싱크대·세탁실 밑 수도관 누수로 인한 곰팡이
2. 옥상·윗집 누수로 천장에 얼룩이 생긴 경우
3. 외벽 단열재 파손으로 벽 전체에 곰팡이가 핀 경우

## 부위별 곰팡이 제거 방법

### 한눈에 보는 부위별 제거 가이드

| 부위 | 사용 약품 | 방법 요약 | 주의사항 |
|---|---|---|---|
| 욕실 실리콘 | 곰팡이 전용 젤 | 도포 → 랩 밀봉 → 30분~1시간 방치 → 헹굼 | 반드시 환기, 고무장갑·마스크 착용 |
| 벽지 (점 형태) | 70% 알콜 (소독용) | 분무 → 5분 대기 → 극세사 수건으로 닦기 → 드라이어 건조 | **락스 원액 절대 금지** (변색 → 도배비 청구) |
| 창틀·문틀 패킹 | 곰팡이 전용 젤 | 칫솔에 묻혀 결 따라 문지르기 → 안쪽은 면봉 → 10분 후 닦기 | 매일 아침 결로수 닦는 습관 병행 |
| 옷장 내부 | 70% 알콜 | 옷 전부 꺼냄 → 알콜 닦기 → 옷 고온 세탁(60도) → 제습제 3통 배치 | 겨울옷 보관 시 압축팩 활용 |

### 욕실 실리콘 — 상세 순서

검정색·회색 점이 실리콘 안쪽으로 파고든 유형이에요. 칫솔로 문질러서는 안 지워집니다.

1. 환풍기 켜고 창문 열기
2. 곰팡이 부위에 제거 젤 넉넉하게 도포
3. **랩으로 밀봉** — 약품이 마르지 않게 하는 게 핵심
4. 30분~1시간 방치
5. 물로 충분히 헹굼
6. 완전 건조 후 곰팡이 방지 코팅 스프레이 도포

랩 밀봉이 효과를 좌우합니다. 그냥 뿌리기만 하면 약품이 흘러내려서 효과가 반감돼요.

### 벽지 — 상세 순서

여기서 가장 중요한 한 가지. **락스 원액을 벽지에 절대 쓰지 마세요.** 벽지 변색으로 이사 시 도배비 15~30만 원을 청구당할 수 있습니다.

1. 알콜을 분무기에 담아 곰팡이 부위에 분사
2. 5분 대기 (이 사이에 곰팡이 사멸)
3. 마른 극세사 수건으로 살살 닦기
4. 헤어드라이어로 완전 건조
5. 해당 벽 앞에 가구를 밀착하지 말 것 — 최소 3cm 이격으로 공기 순환 확보

### 옷장 내부 — 옷에 이미 퍼졌을 때

옷장 벽뿐 아니라 옷 자체에 곰팡이가 번식했을 수 있어요.

1. 옷 전부 꺼내기
2. 옷장 내부에 알콜 분무 후 마른 걸레로 닦기
3. 곰팡이 묻은 옷은 60도 이상 고온 세탁 → 햇볕 건조
4. 제습제(물먹는 하마 등) 최소 3통 배치
5. 숯이나 탈취제 병행 시 냄새 제거 효과

겨울옷을 여름 동안 보관할 때는 압축팩이 곰팡이 예방에 효과적입니다.

## 재발 방지 — 환기·제습·단열 3각 루틴

제거만 하고 끝내면 2~3개월 뒤 재발합니다. 환경을 바꿔야 해요.

![깨끗하게 관리된 욕실](https://images.unsplash.com/photo-1584622650111-993a426fbf0a?w=800&auto=format&fit=crop&q=80)

### 제습 방법 비교

| 방법 | 월 비용 | 제습 능력 | 적합한 상황 |
|---|---|---|---|
| 제습기 (6L/일급) | 15,000~25,000원 | 높음 | 장마철, 반지하 |
| 에어컨 제습 모드 | 20,000~30,000원 | 중간 | 여름철 냉방 겸용 |
| 물먹는 하마 등 화학 제습제 | 5,000원 | 낮음 | 옷장·신발장 등 밀폐 공간 |
| 숯·규조토 | 초기 비용만 | 매우 낮음 | 보조 수단 |
| 환기 (창문 개방) | 0원 | 중간 | 맑은 날 상시 활용 |

### 환기 루틴 (비용 0원)

- 하루 2번, 각 10분. 아침 1회, 저녁 1회.
- 대각선 방향 창문 2개를 동시에 열면 공기 흐름이 최대화돼요
- 비 오는 날이나 미세먼지 심한 날에는 욕실 환풍기만 30분 가동

### 제습 목표

실내 습도 40~50%를 유지하는 게 목표입니다. 습도계 하나(5,000원)만 있으면 눈으로 바로 확인 가능해요. 60%를 넘기면 제습기나 에어컨 제습 모드를 가동하세요.

### 단열 보강 (계절 시작 시 1회)

- 결로 발생 부위에 단열 뽁뽁이 부착 (1만 원대)
- 창문 틈새에 문풍지 (3,000원) — 결로 감소 + 난방비 절약
- 10~11월에 한 번 해두면 봄까지 유지

## 월별 관리 캘린더

| 월 | 주의 포인트 | 해야 할 것 |
|---|---|---|
| 1~2월 | 결로가 가장 심한 시기 | 매일 아침 창틀 닦기, 문풍지 상태 점검 |
| 3~4월 | 환기 본격 시작 | 옷장·신발장 열어 햇볕 소독 |
| 5~6월 | 장마 직전 대비 | 제습기 점검, 욕실 실리콘 상태 확인·재코팅 |
| 7~8월 | 곰팡이 최대 위험기 | 제습기 상시 가동, 매일 습도 체크 |
| 9~10월 | 환절기 | 옷장 대청소, 숯 교체 |
| 11~12월 | 난방 시작 | 단열 점검, 뽁뽁이 시공 |

5~6월 사전 준비가 가장 중요합니다. 장마가 시작되면 이미 늦어요.

## 흔한 실수 5가지 — 이건 하지 마세요

| 실수 | 결과 |
|---|---|
| 락스 원액을 벽지에 사용 | 벽지 변색 → 이사 시 도배비 청구 (15~30만 원) |
| 신문지로 덮어둠 | 습도만 올라가고 곰팡이 2배 번식 |
| 식초 + 베이킹소다 혼합 사용 | 중성화되면서 살균 효과 0 (둘 중 하나만 써야 함) |
| 곰팡이 위에 페인트칠 | 2주 만에 페인트 뚫고 재발 (제거 → 건조 → 칠 순서 필수) |
| 방향제로 냄새만 덮음 | 곰팡이는 계속 성장 + 알레르기 유발 |

## 건강 영향 — 가볍게 볼 문제가 아닙니다

곰팡이 포자는 공기 중에 떠다니다가 호흡기로 들어갑니다. 자취 시작 후 아래 증상이 생겼다면 곰팡이를 의심해보세요.

- 아침마다 콧물이나 기침
- 특정 방에서만 눈이 따가움
- 천식 악화
- 자취방에 있을 때만 피부 가려움

심하면 구청 환경과에 **실내 공기질 측정**을 문의해보세요. 일부 지자체는 무료 측정을 제공합니다.

## 자주 묻는 질문

### "반지하면 곰팡이가 무조건 생기나요?"

"무조건"은 아니지만 확률이 매우 높아요. 제습기가 거의 필수고, 장마철에는 하루 제습량 10L 이상 급 제품이 필요합니다. 소형 제습기로는 감당이 안 돼요.

### "곰팡이 제거 업체 비용은?"

약품비 + 시공비로 20~50만 원 수준. 다만 원인(누수, 단열)을 해결하지 않으면 3~6개월 내 재발합니다. 집주인 책임인 경우 업체 비용 청구가 가능하니 참고하세요.

### "장마철 제습기 전기세가 부담되지 않나요?"

6L/일급 제습기 기준 월 15,000~25,000원입니다. 에어컨 제습 모드보다 오히려 저렴해요. 곰팡이 발생 후 업체 호출 비용(20~50만 원)과 비교하면 훨씬 경제적이죠.

## 오늘 당장 시작할 3가지

1. **습도계 하나 구매** (5,000원)
2. **대각선 창문 2개 열고 10분 환기**
3. **욕실 환풍기를 평소보다 10분 더 가동**

곰팡이는 "청소" 문제가 아니라 **환경 관리** 문제예요. 한 번 크게 잡아놓고 환기·제습·단열 루틴만 유지하면 1년 내내 깨끗하게 살 수 있습니다.

습도 관리가 되면 [청소 주기표](/cleaning)의 다른 항목들도 훨씬 수월해져요. 습도가 모든 청소의 출발선이라는 점, 기억해두세요.
