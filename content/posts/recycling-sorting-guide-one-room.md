## 핵심 요약 — 분리배출 5대 분류

먼저 전체 구조부터 잡고 갑니다.

| 분류 | 대표 품목 | 핵심 주의사항 |
|------|----------|-------------|
| 종이류 | 택배 상자, 과자 상자, 신문지 | 테이프 제거 필수. 오염된 종이는 일반쓰레기 |
| 플라스틱 | 페트병, 배달 용기, PP 용기 | 라벨 제거 + 내용물 세척 |
| 비닐류 | 과자 봉지, 택배 뽁뽁이, 마트 비닐 | 오염되면 일반쓰레기 |
| 캔·고철 | 맥주캔, 참치캔, 금속 뚜껑 | 내용물 비우고 헹구기 |
| 유리병 | 소주병, 잼 병, 음료병 | 뚜껑은 재질별로 따로 분리 |

환경부 2025년 자료 기준, 재활용 가능 폐기물의 약 30%가 잘못된 분리배출로 소각 처리됩니다. 제대로 분류하면 종량제 봉투 사용량도 줄어들어 직접적으로 돈이 절약돼요.

## 품목별 분리배출 총정리표

자취하면서 한 번쯤 "이거 뭔데?" 했을 품목들을 한 번에 정리했습니다.

| 품목 | 분류 | 비고 |
|------|------|------|
| 택배 상자 | 종이류 | 테이프 반드시 제거 후 접어서 배출 |
| 과자 상자 | 종이류 | 비닐 코팅 안 된 것만 |
| 우유팩 | 종이류 (별도) | 씻어서 말린 뒤 별도 배출 |
| 기름 묻은 치킨 박스 | **일반쓰레기** | 기름 오염 = 재활용 불가 |
| 기름 묻은 피자 상자 | **일반쓰레기** | 위와 동일 |
| 영수증 | **일반쓰레기** | 감열지라서 재활용 불가 |
| 코팅된 광고 전단지 | **일반쓰레기** | 반질반질한 건 코팅지 |
| 페트병 | 플라스틱 (PET) | 라벨 떼고, 찌그러뜨려 배출 |
| 배달 플라스틱 용기 | 플라스틱 | 깨끗이 세척 후 배출. 세척 힘들면 일반쓰레기 |
| 스티로폼 배달 용기 | 스티로폼류 | 깨끗이 씻어야 재활용. 안 되면 일반쓰레기 |
| 과자·라면 봉지 | 비닐류 | 깨끗한 것만. 스프 가루 묻으면 일반쓰레기 |
| 택배 뽁뽁이 | 비닐류 | 테이프 제거 후 |
| 맥주캔·참치캔 | 캔류 | 내용물 비우고 헹구기 |
| 소주병·맥주병 | 유리병 | 뚜껑 분리 (플라스틱 or 금속 따로) |
| 깨진 유리 | **일반쓰레기** | 신문지로 감싸고 "깨진 유리" 표기 |
| 아이스팩 (물) | 비닐류 | 물 빼고 비닐만 배출 |
| 아이스팩 (젤) | **일반쓰레기** | 젤 타입은 통째로 |
| 칫솔 | **일반쓰레기** | 재활용 불가 |
| 거울 | **일반쓰레기** | 유리처럼 보이지만 코팅 때문에 불가 |
| 형광등 | **별도 배출** | 주민센터·아파트 수거함. 수은 함유 |
| 건전지 | **별도 배출** | 편의점·주민센터 수거함 |
| 헌 옷 | 의류수거함 | 없으면 종량제 봉투 |
| 우산 | 분리 배출 | 뼈대 → 고철류, 천 → 일반쓰레기 |

이 표 하나면 웬만한 상황은 커버됩니다.

## 음식물 쓰레기 vs 일반쓰레기 구분

음식물 쓰레기의 기준은 "동물 사료로 만들 수 있는가"입니다. 딱딱한 뼈나 껍질류는 사료가 안 되기 때문에 일반쓰레기로 분류돼요.

| 음식물 쓰레기 (O) | 일반쓰레기 (X) |
|-------------------|---------------|
| 밥, 반찬, 국물 | 치킨 뼈, 갈비뼈 |
| 과일 껍질 (귤, 사과, 바나나) | 파인애플·호두 껍질 |
| 채소 자투리 | 양파 껍질, 마늘 껍질 |
| 빵, 면 | 달걀 껍질 |
| 상한 음식 | 조개 껍데기, 생선 가시 |

처음 자취할 때 치킨 뼈를 음식물 쓰레기에 버렸다가 관리사무소에서 연락이 온 적이 있어요. 뼈는 동물이 먹을 수 없으니까 음식물이 아니라는 거였죠.

자취방에서 음식물 쓰레기 냄새와 벌레가 고민이라면, 작은 밀폐 용기에 담아서 냉동실에 보관하다가 버리는 날 꺼내는 방법이 있습니다. 냄새도 안 나고 벌레도 안 꼬여요. 자취생들 사이에서 꽤 유명한 방법이에요.

## 종이류 — 생각보다 재활용 안 되는 게 많습니다

종이라고 전부 재활용되는 건 아닙니다. 기름에 오염되거나 코팅 처리된 종이는 일반쓰레기예요.

자취하면서 제일 많이 나오는 택배 상자는, 뜯자마자 테이프를 떼고 접어서 현관 옆에 모아두는 게 좋아요. 일주일에 한 번 재활용 날에 한꺼번에 내놓으면 됩니다. 안 그러면 원룸이 상자로 도배돼요.

## 플라스틱 — 라벨 떼는 게 포인트

용기 바닥이나 옆면에 삼각형 재활용 표시(PET, HDPE, PP 등)가 있으면 재활용 가능합니다. 핵심은 **라벨 제거**예요. 페트병의 비닐 라벨은 점선을 따라 뜯어서 비닐류로 따로 버려야 합니다.

배달 용기는 설거지할 때 같이 한번 헹궈서 바로 분리배출함에 넣는 게 가장 편한 방법이에요. 따로 하려면 귀찮은데 설거지 타이밍에 같이 하면 별로 번거롭지 않더라고요. 오염된 플라스틱을 재활용에 넣으면 다른 깨끗한 재활용품까지 못 쓰게 되니까, 세척이 힘들면 차라리 일반쓰레기로 버리세요.

![청소 스프레이를 들고 있는 모습](https://images.unsplash.com/photo-1563453392212-326f5e854473?w=800&auto=format&fit=crop&q=80)

## 비닐류 — 깨끗한 것만 재활용

과자 봉지, 라면 봉지, 택배 뽁뽁이, 마트 비닐봉투, 지퍼백 등이 비닐류에 해당됩니다. 한 봉투에 모아서 배출하면 돼요.

다만 음식물이 묻은 비닐은 재활용이 안 됩니다. 라면 봉지에 스프 가루가 잔뜩 묻어 있으면 일반쓰레기예요. 솔직히 라면 봉지 하나하나 씻기는 현실적이지 않죠. 깨끗한 건 비닐류로, 오염된 건 종량제 봉투에 넣으세요. 완벽하려다 지치면 아예 안 하게 되니까, 할 수 있는 선에서 하는 게 낫습니다.

## 캔·유리병 — 비교적 간단한 분류

캔은 내용물 비우고 한번 헹궈서 캔류에 넣으면 끝입니다. 찌그러뜨려도 되고 안 해도 돼요.

유리병도 마찬가지인데, 뚜껑은 재질별로 분리해야 해요. 소주병 뚜껑은 플라스틱이니까 플라스틱류로, 잼 병 뚜껑은 금속이니까 캔·고철류로. 깨진 유리는 재활용 불가이니 신문지로 감싸고 "깨진 유리"라고 써서 일반쓰레기로 버려야 합니다. 수거하시는 분들 안전을 위해 꼭 지켜주세요.

![색상별로 분리된 재활용 분리수거함](https://images.unsplash.com/photo-1532996122724-e3c354a0b15b?w=800&auto=format&fit=crop&q=80)

## 원룸에서 분리배출 깔끔하게 하는 팁

원룸에 쓰레기통 5개를 놓을 공간은 없죠. 현관 옆에 큰 종이 쇼핑백 하나만 놔두세요. 재활용품을 대충 모아뒀다가 버리러 갈 때 분류해서 내놓으면 됩니다.

종량제 봉투는 5리터짜리를 추천해요. 자취하면 쓰레기가 생각보다 적게 나옵니다. 20리터짜리를 사면 채우기도 전에 냄새 나서 반만 채워 버리게 되더라고요. 작은 걸로 자주 버리는 게 낫습니다.

분리배출 요일과 시간은 반드시 확인하세요. 시간 안 지키면 과태료가 나올 수도 있어요. 캘린더에 매주 알람을 걸어두면 까먹을 일이 없습니다.

## 처음부터 완벽할 필요는 없어요

4년째 자취 중인데 아직도 가끔 헷갈리는 품목이 있습니다. 확실히 아는 건 분리배출하고, 헷갈리면 일반쓰레기에 넣으면 돼요. 오염된 재활용품을 섞는 것보다 차라리 일반쓰레기로 버리는 편이 낫습니다.

분리배출을 제대로 하기 시작한 뒤로 종량제 봉투 사이즈를 10리터에서 5리터로 줄였어요. 한 달 봉투값만 수천 원 절약되죠. 환경에도 좋고 지갑에도 좋으니까, 루틴으로 만들어두면 손이 알아서 분류하게 됩니다.
